# Exercise 4.3 – D3 set up

Sets up a responsive SVG container with D3, ready to hold the bar chart built in the exercises that follow.

## Files
- `index.html` – page with an empty `.responsive-svg-container` div for D3 to build the chart into
- `css/style.css` – keeps the container centred and responsive (`max-width`, `margin: auto`)
- `js/main.js` – creates the `<svg>` inside the container with `viewBox`, plus a hard-coded test rectangle to check the setup works before real data is loaded in Exercise 4.4
