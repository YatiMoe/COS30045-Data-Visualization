# Exercise 4.3 – D3 set up

Sets up a responsive SVG container with D3, with a hard-coded test rectangle to check the setup works.

The folder is the ApplianceWatt website with **Exercise 4.1** and **Exercise 4.3** in the navigation. It shows only the answers up to this exercise.

## Files
- `index.html`, `televisions.html`, `about.html` – the ApplianceWatt website pages (Exercise 0.2 site)
- `exercise4-1.html` – the Exercise 4.1 answer (SVG house)
- `exercise4-3.html` – the Exercise 4.3 answer. Step 1: the empty SVG container and test rectangle.
- `assets/css/style.css` – site styling
- `assets/js/main.js` – site navigation script
- `assets/js/chart-stages.js` – draws the step-by-step charts shown on the page
- `assets/data/tvBrandCount.csv` – data used by the page
- `css/style.css`, `js/main.js` – the original exercise files (container styling, and the D3 set-up code)
