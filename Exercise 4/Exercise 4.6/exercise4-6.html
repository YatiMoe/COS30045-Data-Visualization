COS30045 · Building the bar chart

Exercise 4.3 – 4.6

Steps 1-4 of building a D3 bar chart of TV brands, up to a chart that scales to fit its SVG.

01

D3 set up (Exercise 4.3)

Created the responsive SVG container with D3, and checked it with a hard-coded test rectangle before loading any real data.

02

Load data from CSV (Exercise 4.4)

Loaded tvBrandCount.csv with d3.csv, converted count to a number as each row was read, and inspected the data (length, max, min, extent). The exercise itself only logs this to the console – the table below shows the same loaded, typed data.

03

Bind the data and draw bars (Exercise 4.5)

Bound the data to a <rect> per brand with .data(data).join("rect"), using raw pixel values for width and position – the widest bars already run far past a sensible page width.

04

Scale the chart to fit (Exercise 4.6)

Replaced the raw pixel values with a linear scale (xScale) for bar width and a band scale (yScale) for bar height/position, so the chart fits the SVG no matter the data range or the number of brands.
