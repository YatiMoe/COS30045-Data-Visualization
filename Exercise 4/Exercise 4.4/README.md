# Exercise 4.4 – Load data from CSV

Loads `tvBrandCount.csv` with D3 and converts `count` to a number. The website shows the loaded data as a table, since the exercise itself only logs it to the console.

The folder is the ApplianceWatt website with **Exercise 4.1** and **Exercise 4.3-4.4** in the navigation. It shows only the answers up to this exercise.

## Files
- `index.html`, `televisions.html`, `about.html` – the ApplianceWatt website pages (Exercise 0.2 site)
- `exercise4-1.html` – the Exercise 4.1 answer (SVG house)
- `exercise4-4.html` – the Exercise 4.3-4.4 answer. Steps 1–2, stacked: the D3 set-up, then the loaded data.
- `assets/css/style.css` – site styling
- `assets/js/main.js` – site navigation script
- `assets/js/chart-stages.js` – draws the step-by-step charts shown on the page
- `assets/data/tvBrandCount.csv` – data used by the page
- `data/tvBrandCount.csv` – TV brand vs. model count, exported from the provided KNIME workflow (`2026 TV Data.knwf`), grouped by brand and filtered to brands with 20+ models
- `css/style.css`, `js/main.js` – the original exercise files (the CSV-loading code that logs data, length, max, min and extent)
