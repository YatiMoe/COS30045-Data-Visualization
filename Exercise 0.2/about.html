About this project

About Us

This site, ApplianceWatt, is a small demonstration website built for Exercise 0.2 of COS30045 Data Visualisation at Swinburne University. It exists to practise structuring a multi-page site with HTML, styling it consistently with CSS, and adding interactivity with vanilla JavaScript, ahead of the D3.js data visualisation work later in the unit.

01

What this site covers

  • A three-page structure — Home, Televisions, and this About Us page — sharing one consistent navigation and footer.
  • An FAQ accordion on the Home page, built with vanilla JavaScript and no external libraries.
  • An interactive appliance energy calculator on the Televisions page, covering event handling, DOM reading and writing, and input validation.
  • A single external stylesheet applied consistently across every page, styled around the provided power logo.
02

Generative AI use

Generative AI (Claude) was used while building this site to help draft the initial HTML/CSS/JS structure and the calculator logic. The code was then reviewed, tested, and adjusted while building it out. A full, detailed reflection on what was generated, what was changed, and what was learned is kept in this repository's README.md, as required for this exercise.
